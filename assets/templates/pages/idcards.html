Digital ID Cards

👤Connecting…restoring session

Generate branded student/staff ID cards with a locally generated scannable QR code (encodes the person's ID for attendance scanning; no student data is sent to a third-party QR service). Print directly from the browser.

Select a class to filter bulk print — NOT printed on card (lifetime card). Choose "All classes" for whole school.

📐 Finished card size & print layout

Finished card: ISO ID-1 · 85.60 × 53.98 mm. Landscape/Portrait rotates the same physical standard.

The output uses fixed physical millimetres and one student per print unit, so pages cannot flow into the next student. ISO/IEC 7810 ID-1 is the common plastic-card format. Card stock thickness/material is a printer/media choice; nominal ID-1 plastic stock is about 0.76 mm. Use paired-sheet mode for paper/cutting, or duplex mode for a two-sided card printer. Print a test on scrap first and confirm the printer's flip edge.

🪪 Lifetime card: student cards omit class and expiry; staff cards omit expiry. Front and back stay together in the selected paired or duplex output, and every student starts on a fresh sheet.
