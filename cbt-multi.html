🔗 Combine Pre-existing CBTs into Multi-Subject (One-Click) — V12.16

Modus operandi — One-click multi-subject from existing exams:
Already have single-subject CBTs (e.g., Mathematics Mid-term, English Assignment, Biology Exam) and want ONE multi-subject exam (like UTME) without re-pasting CSVs? Select them below and click 🚀 Create Multi-Subject from Selected. The builder will:
1️⃣ Fetch each selected exam's question bank (`csv_data`) from DB (handles JSON array or string).
2️⃣ Tag each question's Section/Subject to its original subject (e.g., all questions from Mathematics exam → Section=Mathematics).
3️⃣ Build subject_breakdown + subjects list (e.g., Mathematics, English, Biology) — same as manual builder.
4️⃣ Publish ONE new multi-subject exam with a single code — students see subject tabs. Original exams stay untouched.
Robustness: Works for any purpose (exam/ca/assignment), any class (must be same class or blank — builder warns if mixed), handles pre-existing multi-subject exams too (splits their breakdown), skips archived, shows question counts, validates at least 2 subjects selected, uses current Term/Session from Step 1 or from first selected exam, uses Purpose from Step 1 (mm-type) so you can create multi-subject Assignment (cumulative) in one click.

Click "Load existing CBTs" to see your current CBT exams (single + multi). Select at least 2 to combine.
