# School Connect V5.4 — Portable Archives, Ordered CBT Library, Adaptive Reports and Student Metrics

## Re-importable exports

V5.4 introduces `assets/js/data-portability.js` and an Admin Data **Portable Data Archive Center**.

- Full JSON archive preserves UUIDs, dates, arrays and JSON objects.
- Table JSON exports carry a format/version manifest and can be upserted later.
- CSV uses quoted RFC-style fields and restores booleans, numbers, arrays and JSON values where possible.
- Exports paginate in 1,000-row ranges rather than silently stopping at Supabase’s default response limit.
- Imports run in dependency order and 200-row chunks, with per-table success/error reporting.
- Generated database columns are removed before import.
- Archives can be analysed locally in the browser without consuming Supabase storage.
- Storage Manager provides “Export selected table first” before purge.
- Every generic CRUD page receives a **Portable JSON** companion beside Export CSV.
- CBT exam packages export the exam/question bank, roster and results together and can be restored from Admin Data.

PDF/print is a presentation document, not a database interchange format. Every underlying dataset now has CSV and/or portable JSON for re-import.

## CBT library organization

The former CBT page rendered an exam more than once under overlapping categories. V5.4 renders each exam exactly once and groups it by session and term.

Filters include search, class, subject, teacher, mode, single/multi subject, term, session, archive status and sort order. Summary cards show active, archived, visible and multi-subject counts.

Staff can archive one exam or all currently filtered exams after a term/session. Archiving automatically closes an exam. Archived exams are hidden from the default active view and can be restored later. Large libraries load in pages up to 5,000 records rather than the old 100-exam limit.

## Adaptive reports

V5.4 retains the V5.3 active-assessment denominator. A CBT-only report uses only pushed CBT maxima; missing manual columns remain dashes. Raw CBT attempts never enter an official report until explicit bulk push.

## Physical/health metrics

The new `student_term_metrics` table stores beginning-of-term measurements by learner, class, term and session:

- height (cm)
- weight (kg)
- calculated BMI
- blood pressure
- vision
- blood group
- genotype
- medical note
- measurement date

Staff enter metrics from Report Cards → **Height / Weight / Health Metrics**. Reports print the matching term/session values. Family roles can read only linked learner metrics through RLS. Blank values print as dashes and are never invented.

## Free-tier operations

Machine archives remain on the administrator’s device; the source files are never uploaded to Supabase. A school can export, purge approved old rows, locally inspect the archive, and later restore selected tables for analysis. Profile UUIDs are tied to Supabase Auth; when moving to a new project, create/adopt users before restoring dependent profile data.
