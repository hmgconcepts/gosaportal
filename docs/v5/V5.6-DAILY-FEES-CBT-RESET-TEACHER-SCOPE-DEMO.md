# School Connect V5.6 — Daily Fees, CBT Result Reset, Teacher Scope and Demo Coverage

## Daily fee collection

Fees now stores a Lagos school-date (`payment_date`) and collector name. Existing payments are backfilled from `created_at` using the Africa/Lagos timezone.

The admin/bursar Daily Fee Collection Dashboard provides:

- selected-day total
- number of transactions
- average receipt
- previous-day total
- month-to-date total
- breakdown by payment method
- breakdown by student class
- breakdown by collector/cashier
- detailed daily transaction ledger
- CSV export for the selected date

New payment records automatically capture the authenticated collector.

## Reusing a CBT examination

CBT Results includes **Export then clear results**.

1. The platform downloads a portable package containing exam settings/question bank, roster and results.
2. The user must type the exact exam code.
3. A final warning explains that previously pushed `report_scores` are separate.
4. The server permits only an admin-like role or the teacher who created the exam.
5. `cbt_results` rows are deleted, resetting attempt counts so a new cohort can sit the same exam.

The action does not silently delete official report scores already pushed; use Report Cards → Audit/Clear Unwanted Scores if those should also be removed.

## Strict teacher subject/class ownership

`teacher_can_manage_subject_class` and `teacher_can_manage_student` enforce assignment from Staff, Subjects and Classes.

- Admin roles retain full control.
- Teachers can create academic rows only for their assigned subject or class.
- Owned rows carry teacher/creator/recorder IDs.
- Another teacher cannot edit or delete them.
- Assigned teachers may claim a genuinely unowned legacy row once; the update assigns ownership.
- Students/parents retain family-safe read access.
- School structure (students, staff, classes, subjects, departments and timetable requirements) is admin-managed.

The contract covers results, attendance, report scores, traits/comments, assignments, schemes, lesson plans, CBT exams/results, digital resources, conduct, behaviour, support plans, diary and term metrics. UI checks improve clarity, but PostgreSQL RLS is the final authority.
