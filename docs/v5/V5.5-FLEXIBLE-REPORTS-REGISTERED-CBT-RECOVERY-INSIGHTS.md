# School Connect V5.5 — Flexible Reports, Registered CBT Identity, Recovery and Academic Insights

## Flexible report headings

Student and subject report tables no longer hard-code CA1/CA2/CA3/Project/Exam maxima. Headings are generated from the exact global `assessment_columns` selected by admin for class + term + session.

Examples supported:

- CA1 (10), CA2 (10), Project (20), Exam (60)
- CA1 (20), CA2 (10), Project (10), Exam (60)
- CBT (100) only
- Practical (40), Theory (60)

Report Cards now lets admin edit each column heading and maximum. A structure audit displays configured total, unusual maxima and duplicate-like names. Renaming a column updates matching CBT report mappings for the same context. The former accumulated `CA3(230)` presentation path has been removed.

## Registered CBT identity

The new `cbt_get_public_exam_v6` and `cbt_submit_v6` enforce identity twice.

- Candidate enters code first.
- Registered exam: only admission number is shown. Official name/class is loaded from Students. If a roster exists, membership is required.
- Open exam: a registered student may enter admission number; an external/random candidate can enter a name/class or continue anonymously.
- Server submission ignores a typed/spoofed registered name and replaces it with the official student record.

## Correct school name

The CBT identity header ignores database placeholders such as `My School`, `School` and `School Portal` when the generated config contains the real school name. The name is shown in the banner, heading and identity card.

## Password recovery

`forgot-password.html` accepts email, admission number or staff number, resolves the linked email where permitted and calls Supabase `resetPasswordForEmail`. Recovery links return to `change-password.html?recovery=1`; after update the user is signed out and returns to login. Configure the live Site URL/redirect URL in Supabase Authentication settings.

## Consistent navigation icons

All sidebar icons now have a fixed 32px container and 18px glyph/image size with consistent emoji font and line height across desktop, mobile and alternate layouts.

## Assistant/page guidance

The School Assistant now constructs full help coverage from the current DOM, catalog and navigation for every page—even pages without a hand-authored entry. Help includes purpose, workflow text, authorised roles, visible actions, key fields, exports, RLS and benefit. Rubrics and Transcripts have explicit first-user guides and worked examples.

## Term/session academic performance

Analytics includes a Decision Center powered by official `report_subject_totals`. Filters: session, term, class and subject. Outputs: school average, pass rate, learners analysed, class performance, subject performance, top learners and at-risk learners. JSON export supports management review and re-import/local analysis.
