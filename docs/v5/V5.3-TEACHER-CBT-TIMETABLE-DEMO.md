# School Connect V5.3 — Teacher Signatures, Full CBT Edit, Adaptive Reports, Timetable and Demo SQL

## Teacher-owned report signatures

Every staff/teacher now has **My teacher signature** on `profile.html`. The teacher pastes a Drive/direct image link and sees a preview. The value is saved to the teacher’s own profile; another teacher cannot change it from this page.

For report-card use:

1. Admin links the teacher’s Staff record to their login account.
2. Admin assigns that staff name in Classes → Class teacher.
3. The teacher saves their full name and signature in My Profile.
4. Student report cards and the class broadsheet resolve the assigned teacher through the narrow `get_class_teacher_identity(class)` RPC and print that teacher’s name/signature.

If no signature is uploaded, the report says “Signature not uploaded”—it never substitutes the currently logged-in administrator’s signature.

## Full CBT editing

CBT Manager → Edit now covers title, subject, class, term, session, assessment type, candidate mode, report destination, destination maximum, duration, attempt limit, selected-question count, negative mark, pass mark, topic, schedule, instructions, open/archive state, randomisation, result release, certificate and entrance mode.

Subject, class, term, session and report destination are platform dropdowns. Report maximum follows the chosen report column. Multi-subject names remain controlled by question sections and Repair Tabs.

## CBT-only report cards

No manual CA/exam score is required.

1. Students complete CBT using the V5.1 verified engine.
2. Staff click **Bulk Push CBT Scores**.
3. Filter/select exams; choose or auto-create a CBT report destination (for example max 10 or max 100).
4. Push once.
5. Generate student reports.

Only the pushed CBT column is active in the denominator. A score 8 in a max-10 CBT column prints `8 / 10` and is graded from 80%. Unentered CA, project and exam cells print `—`; they do not dilute the score and are not saved as zeros.

This same active-column model adapts to any subset of assessments: only CA, only project, two CBTs, practical-only, etc.

## Timetable Admin Wizard

The page now has four numbered steps:

1. Build/save school-day periods and breaks.
2. Pick class, term and session from dropdowns.
3. Pick each subject and teacher, enter periods/week, and restrict part-time days where necessary.
4. Validate capacity, generate/regenerate, review unplaced demands, print or clear the exact context.

The database generator checks restricted days and prevents a teacher being scheduled in two classes at the same term/session/day/period. An executed SQL test confirms both constraints.

## Demo seed `amount` type repair

The generic page-coverage insert now explicitly uses:

```sql
x.amount::numeric
```

This removes PostgreSQL 42804 when every VALUES amount is `NULL` and PostgreSQL initially infers the VALUES column as text. The exact insert is executed in PGlite during verification: 12 rows insert into a numeric `amount` column successfully.

## Deployment

Back up Supabase, run the full updated `database/complete-schema.sql`, deploy all files, close old tabs and hard-refresh. Run `database/demo-seed.sql` only in the separate demo project after the schema update.
