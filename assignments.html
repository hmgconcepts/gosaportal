🖥️ CBT Assignments — Auto-fill from CBT Results (V12.11) — Detailed Guide

Blueprint: Unlike mid-term (CA1/CA2) and terminal exams which are done ONCE per term, assignments are given MORE THAN ONCE per term (e.g., Homework 1, Homework 2, Homework 3). The assignment page already collates individual assignments cumulatively → push to Assignment column of report card. Now CBT assignments work the SAME way but with auto-fill.

Modus operandi for CBT assignments (step-by-step for new users):

  1. Create CBT assignment: Go to CBT page → + New Exam → Assessment type = 🟢 Assignment / Homework (multiple per term, cumulative → Assignment column) → set Class (e.g., JSS1), Subject (e.g., Maths), Term, Session, Max score → add questions → Create. DB trigger auto-creates mirror row in Assignments table with drive_link auto-filled as ./cbt-exam.html?code=CODE and is_cbt=true, so it appears in Assignments page for every student of that class with Take link.
  2. Student view: Every student of that class sees the assignment in Assignments table with 🖥️ Take Assignment button (not in teacher portal). Student clicks Take → does online CBT assignment → result saved in cbt_results with score/total/percent.
  3. Teacher scores class (auto-fill): Assignments → pick Class + Subject → see list below of CBT assignments for that subject → click ✍️ Score class (auto-fill) for THAT CBT assignment → modal auto-fills:
    • Assignment kind (auto-filled): CBT assignment (auto-marked) — disabled, no manual needed
    • Maximum mark (auto-filled): from CBT exam max_score — readonly, scaled to align
    • Scores (auto-filled): for every student of that class from CBT results, scaled to max (e.g., raw 15/20 → scaled 7.5/10 if max=10) — teacher can adjust before saving
    For physical assignments, teacher manually enters kind/max/scores.
  4. Cumulative collation: All assignment scores (physical 📄 + multiple CBT 🖥️ assignments) accumulate per student per class/subject/term: Total got / Total max → %. Each CBT assignment is separate column in Term score sheet (e.g., Assignment1 CBT, Assignment2 CBT, Assignment3 physical).
  5. Push to report card: At end of term, Assignments → 📋 Term score sheet → 🚀 Push totals → Report card → choose Assignment column → push. Assignment column now contains cumulative % of ALL assignments (physical + multiple CBT) scaled to column max.
Clear differentiation (unambiguous) — CBT purposes:
🟢 CBT Assignment = Homework — multiple per term, cumulative → Assignment column (this page) 🔵 Mid-term Assessment = choose CA1/CA2/Midterm as the separate destination (Report Cards → Bulk Push CBT) 🔴 Terminal Exam = Exam — once per term → Exam column (Bulk Push CBT) 🟣 Project / 🟡 Quiz / 🟠 Practical = other purposes → any report column

🏆 Why your assignments earn points — How it works for students

Every assignment you complete earns points that accumulate for each subject through the term. This includes:

  • 📄 Physical assignments — written homework, class exercises, projects, practicals, presentations (teacher scores manually)
  • 🖥️ CBT assignments — online homework done via Take Assignment button (auto-marked, multiple per term). Each CBT assignment is separate and accumulates.

Modus operandi:

  1. Teacher gives assignment (physical or CBT) for your class + subject
  2. You complete it — for CBT, click 🖥️ Take Assignment button in table → do online test → score saved automatically
  3. Teacher clicks Score class for THAT assignment → for CBT, scores auto-fill from CBT results (kind and max auto-filled); for physical, teacher enters manually
  4. All your assignment scores (physical + multiple CBT assignments) accumulate: Total points / Max points → %
  5. At end of term, teacher pushes your cumulative % into Report Card → Assignment column (scaled to column max). More assignments = higher report card score! 💪

Tip: Check your points below. Every assignment counts — the more you do, the higher your Assignment column climbs.

Modus operandi — How assignment scoring works (for new users, step-by-step):

1️⃣ Pick class + subject below — everything on this workbench applies to that pair for the CURRENT term (e.g., JSS1 + Mathematics, First Term).

📄 Physical/paper work:
• ➕ Quick physical assignment → records a physical assignment (e.g., Essay, Worksheet) and opens the class scoring sheet immediately for manual entry of kind/max/scores
• ✍️ Score class on any existing assignment row in table above → for physical assignments, teacher manually enters assignment kind (Written homework, Project, etc.), maximum mark, and each student's score

🖥️ CBT assignments (auto-fill, multiple per term):
• Create on CBT page → type 🟢 Assignment → auto-appears here with Take link for every student
• ✍️ Score class for THAT CBT assignment in table above → auto-fills assignment kind (CBT assignment auto-marked disabled), maximum mark (auto-filled from CBT exam max_score readonly, scaled to align), and scores for every student of that class from CBT results (scaled to max, e.g., raw 15/20 → 7.5/10 if max=10). Teacher can adjust before saving. Only physical requires manual entry.
• 🖥️ Pull CBT scores → bulk syncs ALL CBT assignments for selected class/subject (handles multiple per term) — each assignment separate column, accumulating cumulatively

3️⃣ Review — cumulative collation:
• 📋 Term score sheet shows EVERY assignment (physical 📄 + each CBT assignment 🖥️ as separate column) per student with Total got / Total max and % — e.g., Assignment1 (CBT), Assignment2 (CBT), Assignment3 (physical) → Total accumulates ALL
• Σ Totals only is condensed per-student view: assignments count, points, %
• Print score sheet or export CSV — each column is one assignment

4️⃣ Push — to report card Assignment column:
• 🚀 Push totals → Report card writes each student's cumulative % into chosen report-card column (e.g., Assignment), scaled to that column's max mark (e.g., if Assignment column max=20 and student has 80%, pushed score=16)
