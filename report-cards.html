ℹ️ Report Card Columns Are Global

Report card columns (CA1, CA2, CBT, Project, Exam, etc.) are defined once for all subjects. You do not need to set up columns separately for each subject. All subjects use the same column structure.

Flexible structure: create or edit any heading and maximum—e.g. CA1 (20), CA2 (10), Project (10), Exam (60), or CBT-only (100). Printed headings and CBT destinations follow these exact settings; no hard-coded CA maximum is used.
