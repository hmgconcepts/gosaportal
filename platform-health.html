📋 How Layers Protect Against Pausing (from DramaConnect)

Supabase free tier pauses after 7 days without DB activity. Configure 2-3 external automated layers, not every layer. Site visits stop during holidays, so automated layers (GitHub Actions, Vercel Cron, cron-job.org, Edge + UptimeRobot, Fleet Console workflow) keep project alive unattended. Manual button is for holidays. Auto-restore watchdog can un-pause via Management API if SUPABASE_ACCESS_TOKEN set. This page shows when each layer last carried out its function and its fix if never.
